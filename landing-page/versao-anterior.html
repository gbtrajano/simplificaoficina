Antes de começar

Respostas diretas.

O Simplifica Oficina tem mensalidade?

Sim. O sistema funciona por assinatura mensal. É necessário manter a assinatura ativa para continuar utilizando o programa. Não se trata de uma compra de licença vitalícia.

Posso instalar no celular?

O instalador disponibilizado nesta página é para computadores Windows de 64 bits. Você pode navegar por este site no celular, mas deve abrir a página de download no computador para instalar o sistema.

Onde ficam os dados da oficina?

Clientes, veículos, serviços e ordens de serviço ficam no arquivo DB local, armazenado no computador. Em Configurações → Dados do Sistema, você pode localizar esse arquivo. Mantenha cópias de segurança em um local seguro, de preferência fora do computador da oficina.

O orçamento é enviado automaticamente pelo WhatsApp?

Não. O sistema prepara uma mensagem com o orçamento. Você confere, copia e cola no WhatsApp para enviar ao cliente.

Preciso de internet?

Você precisa de conexão para baixar o instalador e acessar os serviços online de conta, licença e atualização. Os registros operacionais da oficina ficam no banco de dados local.

Como faço para instalar?

Acesse a página de download, baixe o instalador Windows e siga o guia de instalação disponível logo abaixo do botão.

Importante: faça backup. A perda do arquivo DB sem uma cópia de segurança pode causar a perda definitiva dos dados. Preserve esse arquivo antes de formatar ou trocar o computador.
