Dúvidas frequentes

Antes de colocar sua oficina no controle

Preciso entender de informática para usar?+

Não. O sistema foi pensado para ser direto, com telas claras e um fluxo fácil de aprender.

Consigo consultar o histórico de cada veículo?+

Sim. Os atendimentos ficam vinculados ao cliente e ao veículo, facilitando consultas futuras.

O sistema ajuda no controle financeiro?+

Sim. Você pode acompanhar receitas, despesas, contas e indicadores da operação em um só lugar.

Posso cadastrar minha equipe?+

Sim. O plano único inclui a conta do proprietário e até 10 contas para a equipe.

O sistema possui mensalidade?+

Sim. A assinatura tem cobrança mensal recorrente e precisa estar ativa para utilizar o sistema. A licença não é vitalícia e o download do instalador não substitui a contratação.

Onde meus dados ficam salvos?+

Clientes, veículos, serviços e ordens de serviço ficam no arquivo DB local do computador. Acesse Configurações → Dados do Sistema para localizar esse arquivo. Mantenha cópias de segurança fora do computador da oficina.

Funciona no celular? Preciso de internet?+

Este site pode ser acessado pelo celular, mas o instalador é para Windows de 64 bits. É necessária conexão para baixar o programa e acessar os serviços online de conta, licença e atualização.

Faça backup do arquivo DB. A perda desse arquivo sem uma cópia de segurança pode causar a perda definitiva dos dados. Guarde cópias em um local seguro antes de formatar ou trocar o computador.
