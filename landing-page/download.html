Do download ao primeiro acesso

Instalar é simples.

Siga os passos abaixo no computador que será utilizado na oficina.

  1. 01

    Baixe o instalador

    Use o botão de download acima. Aguarde o arquivo .exe terminar de baixar antes de abri-lo.

  2. 02

    Abra o arquivo

    Abra a pasta Downloads do Windows e dê dois cliques no instalador do Simplifica Oficina.

  3. 03

    Siga a instalação

    Siga as instruções do assistente e aguarde a conclusão. Se houver um pedido de permissão, confira a origem do arquivo antes de aceitar.

  4. 04

    Acesse sua oficina

    Abra o Simplifica Oficina pelo menu Iniciar. Siga as orientações de acesso e ativação exibidas no sistema.

Antes de começar

Use um computador com Windows de 64 bits e conexão com a internet para baixar o instalador e acessar os serviços de conta, licença e atualização. Este instalador não é destinado a Android, iPhone ou macOS.

Precisa de uma orientação?

Dúvidas na instalação

Alguns cuidados para começar com tranquilidade.

O download não começou. O que faço?

Use o link “Download alternativo e versões disponíveis”. Na página da versão, procure a área de arquivos (Assets) e baixe o instalador que termina em -setup.exe. Arquivos de código-fonte e de assinatura (.sig) não são instaladores.

O Windows exibiu um alerta de segurança.

Não desative o antivírus. Confira se o arquivo veio do canal de distribuição indicado nesta página. Se o alerta persistir ou você não tiver certeza da origem, interrompa a instalação e procure o suporte responsável pelo sistema.

O sistema tem mensalidade?

Sim. A licença funciona por assinatura mensal e precisa estar ativa para utilizar o sistema. Baixar ou instalar o programa não substitui a contratação da assinatura.

Onde ficam os dados da minha oficina?

Clientes, veículos, serviços e ordens de serviço são armazenados no arquivo DB local do computador. No sistema, acesse Configurações → Dados do Sistema para localizar o arquivo.

Seus dados merecem cuidado. Faça backup.

Guarde cópias do arquivo DB em um local seguro, de preferência fora do computador da oficina. Se esse arquivo for perdido e não houver uma cópia de segurança, os dados podem ser perdidos definitivamente. Antes de trocar de computador, formatar ou reinstalar o sistema, preserve seu banco de dados.
